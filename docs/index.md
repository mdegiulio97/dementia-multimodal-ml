# dementia-multimodal-ml

Multimodal biostatistics and machine learning for dementia research:

- MCI-to-dementia conversion on ADNI;
- open-data Mendelian randomisation of circulating proteins and metabolites on Alzheimer's
  disease;
- resting-state EEG classification of AD, FTD and controls;
- a local tool-using agent over the results.
